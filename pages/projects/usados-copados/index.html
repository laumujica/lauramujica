UI design · FigmaConcept project · Professional mentorship

A brand-led mobile interface built as a reusable system.

Usados Copados is a conceptual peer-to-peer marketplace for second-hand goods. I designed the interface and organized its visual foundations, reusable components, states, and functional prototype in Figma.

This case study focuses on the UI design within a complete UX project spanning research, UX design, and UX writing.

01 / Visual direction

A bold identity carried into every screen.

The visual direction combines bright color, organic geometry, and a direct typographic voice. Its three guiding ideas—ecological, honest, and positive—shaped the interface without turning the project into a separate branding exercise.

Logo system

A bold wordmark with a reusable symbol.

The lightning symbol works as a compact brand cue across navigation, loading states, and interface details.

Graphic language

Organic shapes keep the system recognizable.

Circles, arcs, rounded blocks, and small triangular patterns carry the identity beyond the logo without competing with the interface.

02 / Figma foundations

Shared rules before individual screens.

I documented the core visual decisions in one Figma workspace so typography, color, layout, and spacing could be applied consistently throughout the interface.

Typography

Role-based scale

Roboto Flex styles for titles, labels, body copy, buttons, and product cards.

Color

Functional roles

Brand colors supported by neutral, success, warning, error, and information families.

Layout

4-column structure

A mobile grid with 16 px margins and gutters for predictable alignment.

Spacing

8 px foundation

A spacing rhythm based on multiples of eight across layouts and components.

03 / Components

Reusable patterns, visible states, organized layers.

The UI kit gathers recurring patterns in one place: navigation, product cards, buttons, search, segmented controls, feedback messages, galleries, ratings, illustrations, and dialog states.

Atomic organization

Names describe both level and purpose.

The file uses atomic naming to expose hierarchy and reuse. The photo slider, for example, is organized as an organism with named component instances for each image state.

04 / Applied interface

The visual system stays recognizable across different journeys.

Full screen sequences show how the identity and reusable patterns work together—from the first brand impression to browsing, account activity, conversation, and feedback.

06 / Conclusion

An idea shaped by design and real feedback.

Usados Copados gave me a complete design loop: start from a personal observation, investigate the market, model the information, build a testable flow, receive professional feedback, watch people use it, and let those observations change the interface.

The Figma prototype showed that its core tasks could be understood by the five people I tested with, while revealing issues around language, legibility, and state. The later Business Model Canvas and year-long Empretienda (usadoscopados.ar) experiment explored the idea from different angles; they did not validate the native app, environmental impact, or accessibility at scale.

Beyond this conceptual project, Usados Copados is an idea I would love to bring to life as a working product someday.
