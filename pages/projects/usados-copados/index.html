02 / Design System & Figma Architecture

Design System & Figma Architecture

Rather than designing isolated screens, I built a centralized UI library in Figma using Atomic Design principles. The goal was to ensure visual consistency, speed up prototype iterations, and simulate a real-world production environment ready for developer handoff.

01 / Foundations

Grid & Spacing Foundations

Established an 8-point grid system and a four-column mobile layout. The foundations use 16 px margins and gutters, with a spacing scale based on eight to maintain rhythm and visual balance.

02 / Foundations

Styles & Token Hierarchy

Defined 16 modular typography styles using Roboto Flex and 23 paint styles covering primary, secondary, neutral, and semantic feedback roles. Named local text and paint styles form the token layer; migration to Figma Variables would be a next step.

03 / Foundations

Reusable Components & Layout

Built reusable navigation bars, product cards, buttons, search, forms, and feedback patterns. Atomic naming connects atoms, molecules, and organisms so repeated interface decisions remain consistent across screens.

04 / Foundations

Variants & Interface States

Organized components and variants for navigation, segmented controls, image sliders, dialogs, ratings, and status feedback. Selected and active states help make the available actions and current position visible.

03 / Interface Evolution: Wireframes to High-Fi

Interface Evolution: Wireframes to High-Fi

Translating functional wireframes into high-fidelity screens required refining visual hierarchy, contrast, and interactive feedback.

Navigation & Header

Refined bottom tab bar active states and simplified top bar actions to reduce cognitive load during search.

Card Design & Scannability

Strengthened text hierarchy and reduced content density so product information is easier to scan.

Form Controls & Media Upload

Revisited the upload icon, guidance, and feedback after participants misread the original photo-upload pattern.

05 / UX Foundation & Navigation Strategy

UX Foundation & Navigation Strategy

While the primary focus was on UI execution, all interface decisions were grounded in lightweight user research and information architecture validation.

Card Sorting · 10 participants

A hybrid sort of 20 content cards informed the navigation structure and exposed ambiguous labels.

User Testing · 5 participants

Moderated sessions identified friction around Sell vs. Offer, photo upload, legibility, and navigation states. These observations guided interface revisions.

Architecture · 3 core actions

Publish, search, and evaluate the seller form a connected task flow. The primary navigation is Home, History, Publish, and My Account.

06 / Takeaways

Key Takeaways & UI Next Steps

Designing with systemization in mind dramatically accelerates layout iteration.

Prototyping realistic component states reveals visual edge cases earlier in the design process.

If continuing development, the immediate next step would be migrating local styles to Figma Variables for multi-theme support (Dark Mode) and building a comprehensive design token handoff document for front-end engineers.
