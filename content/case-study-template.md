## Repeatable workflow
1. Gather Behance, Lemon.ai, GitHub, original files and any project-specific context.
2. Extract claims with source IDs; identify conceptual versus commissioned work and separate in-world dates from actual dates.
3. Propose an angle and media sequence, then ask only for unresolved facts that affect the story.
4. Draft the page in the project's voice while retaining shared navigation, structure, accessibility and credits.
5. Review tool attribution, visual evidence, rights, factual claims and final QA with Laura.
6. Build the HTML and scoped CSS; add project JS only when necessary. Verify responsive layout, links, media, and motion preference.
